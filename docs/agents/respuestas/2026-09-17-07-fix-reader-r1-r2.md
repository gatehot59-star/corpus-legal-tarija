## Contrato elegido

Una fuente seleccionada debe tener base real, directorio texto real y normas.jsonl regular existente. Manifiesto ausente genera SourceConfigurationError, subclase ValueError: se debe abortar la ingesta de esa fuente, no convertir excepción a censo0. Un manifiesto existente vacío o solo comentarios sigue válido como vacío explícito. Los archivos de texto no inventariados no se incorporan por la existencia de ese directorio.

La ruta de fuente no puede contener symlinks: base, padres, texto, manifiesto yarchivo final. Se revisan componentes léxicos antes de resolver. La raíz texto se revalida antes de cada lectura. Esto rechaza también el enlace estático detectado por la auditoría, sin invocar una carrera concurrente.

El árbol de fuente debe permanecer inmutable durante el lote. No se promete protección TOCTOU ni defensa contra un atacante local de mismo UID, ni límites de tamaño/FIFO del archivo de texto. El resultado válido sigue siendo texto/ruta; los errores de fila mantienen None/faltantes. El constructor pasa a fallar ante configuración inexistente/indirecta. Los callers deberán propagar ese error; no se integró aquí el lector con producción.

Una fuente alojada legítimamente detrás de symlinks debe configurarse mediante la ruta física autorizada antes de arrancar, o proponer otra política explícita en un cambio posterior. No se resuelve un symlink recibido automáticamente para saltar esta regla.
